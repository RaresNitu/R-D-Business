    Make it public or share

    The analyzer is just a single index.html file. Serve it locally or host it anywhere that supports static files—no backend needed.

    • For yourself: open index.html directly in the browser, or run a local server with python -m http.server 8000 and visit http://localhost:8000.
    • To share privately: zip the folder and send it, or place index.html on a USB drive—everything works offline.
    • To publish: drop the file into any static host (GitHub Pages, Netlify, Vercel). On GitHub Pages, push this repo and enable Pages for the work branch so friends can try it from a link.
